# GitHub Code Explainer (Initial GenAI Prototype)

> **Initial proof-of-concept repository for local LLM-assisted source code explanation.**

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python&logoColor=white)](https://python.org)

---

## 1. Overview

This repository represents the initial proof-of-concept prototype exploring the integration of local LLMs (Ollama) with repository AST parsing.

- `backend/`: Code parsing and token chunking routines.
- `frontend/`: Prototype UI interface.
- `test_ollama.py`: Integration test verifying local Ollama connectivity and latency.

*For the latest mature applications, refer to [GITHUB-CODE-EXPLAINER](https://github.com/keerthi19hub/GITHUB-CODE-EXPLAINER).*
